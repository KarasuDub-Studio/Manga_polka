Манга колекція: встановлення на телефон

1. Завантажте всю цю папку на будь-який безкоштовний хостинг із https:
   Netlify (app.netlify.com/drop), Cloudflare Pages або GitHub Pages.
   Папку не розпаковуйте по частинах: index.html, manifest.webmanifest, sw.js і папка icons мають лежати разом.
2. Відкрийте отримане посилання на телефоні.
   Android (Chrome): меню ⋮, «Встановити застосунок» (або «Додати на головний екран»).
   iPhone (Safari): «Поділитися», «На екран «Додому»».
3. Іконка з вашою картинкою з’явиться на головному екрані, а застосунок відкриватиметься на весь екран і працюватиме без інтернету.

Дані зберігаються в пам’яті застосунку на телефоні. Раз на кілька тижнів робіть бекап: меню (три смужки), «Завантажити бекап».
